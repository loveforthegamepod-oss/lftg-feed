# LFTG Performance Index (public site)

Live college football model by Love For The Game: best bets, line movement, live betting board, power ratings, Upset Alert Meter, team pages with fan mood and two-deep charts.

- Site: https://lftgcfb.app
- Site code lives on `main`. Data (`core.json`, `live.json`, `files/*`) is pushed to the `data` branch every few minutes by the LFTG model.
